TEACHER’S NOTE

관찰에서 평어로

단원별 관찰 기록을 정리하고, 학생의 배움이 드러나는 평어 초안을 만드세요.

관찰한 사실을 입력하면 두 가지 문장 구성으로 정리합니다.

외부 AI API 없이 · 템플릿 기반

01. 관찰 기록 입력

모든 항목을 입력해 주세요. 실제로 관찰한 내용을 적어 주세요.

관찰 내용이 없으면 평어를 생성하지 않습니다.

쉼표(,)로 구분해 입력하세요. 입력한 키워드만 문장에 반영합니다.

02. 평어 초안

생성한 문장은 직접 수정하고 복사할 수 있습니다.

2가지 구성
✎관찰 기록이 문장이 되는 곳

왼쪽 항목을 입력하고
‘평어 초안 2개 만들기’를 눌러 주세요.

초안은 입력 내용과 정해진 문장 템플릿을 조합한 결과입니다. 학생의 실제 수행과 성취 기준에 맞게 교사가 확인·수정한 뒤 활용해 주세요.

03. 학생별 기록 목록

수정한 평어와 관찰 기록을 함께 저장합니다. 기록을 누르면 다시 편집할 수 있습니다.

작성 중 내용은 이 브라우저에 자동 저장됩니다. 외부로 전송하지 않습니다. 공용 기기에서는 기록 삭제와 입력 초기화를 해 주세요.
