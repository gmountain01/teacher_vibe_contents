# 교사 바이브 코딩 목차 아이디어

선생님들이 엑셀(구글 드라이브)에 적어 주신 웹앱 아이디어를 보기 좋게 정리한 페이지입니다.

사이트: https://gmountain01.github.io/teacher_vibe_contents/

- 수업자동화 / 업무자동화 탭, 교과×단계 분포표, 단계·교과·제안자별 보기, 검색
- GitHub Actions가 **매시 17분**에 드라이브 엑셀을 내려받아 `data.json`을 새로 만들고 다시 배포합니다.
- 바로 갱신하려면: Actions 탭 → "엑셀 데이터 갱신 및 배포" → Run workflow

## 최종 목차
- 드라이브 엑셀에 `최종목차` 탭을 만들면 그 내용이 '최종 목차' 페이지에 나옵니다. 탭이 없으면 `draft_toc.json`(가목차 초안)을 보여 줍니다.
- 탭 양식과 가목차 초안: `엑셀양식/` 폴더

## 파일
- `index.html` — 페이지 (`data.json`을 읽어 그림. 못 읽으면 내장된 정리 시점 데이터 표시)
- `scripts/build_data.py` — 엑셀 → `data.json` 변환
- `.github/workflows/update.yml` — 1시간마다 갱신·배포

## 조건
- 엑셀 파일 공유: "링크가 있는 모든 사용자 – 뷰어"
- 탭 이름 `수업자동화`, `업무자동화`와 열 순서(번호·교과/영역·단계/시기·앱 이름·장면·도구·제안자·링크·비고)를 유지
- 파일을 바꾸면 `scripts/build_data.py`의 `FILE_ID`를 수정
